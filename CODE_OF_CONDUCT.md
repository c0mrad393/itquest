# Code of Conduct

## The short version

Be decent. Assume good faith. Critique the work, not the person.

## What is expected

- Welcome people who are new to the subject. This is a teaching project; someone
  asking a basic question about Active Directory or DHCP is exactly who it is for.
- Give feedback on the substance. "This binds unreliably because it picks before
  filtering" is useful; "this is bad" is not.
- Accept that the answer is sometimes no, and say no kindly.

## What is not

Harassment, personal attacks, demeaning comments, unwelcome attention, publishing
others' private information, or sustained disruption. Any of these will get a
contribution closed and, if repeated, the person blocked.

## Scope

This applies in issues, pull requests, discussions and any other space where you
are representing the project.

## Reporting

Report a problem by opening a
[private security advisory](https://github.com/c0mrad393/itquest/security/advisories/new),
which is the only confidential channel this repository has. Reports are read by
the maintainer and handled discreetly.

This project is not actively developed, so enforcement is best-effort. Blocking
and closing are the tools available and they will be used when warranted.

shortened to what a project this size can actually honour.
